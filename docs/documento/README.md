# Documento del proyecto

- `../../FruitAI_documento.docx`: documento completo (el original corregido + las secciones
  nuevas). Las marcas amarillas `[PENDIENTE: …]` son datos que faltan del hardware.
- `generar.js`: genera el .docx (`node generar.js ../../FruitAI_documento.docx`, requiere el
  paquete `docx` de npm). Editar el texto aquí y regenerar cuando lleguen los resultados.
- `diagramas.py`: dibuja `arquitectura.png` y `estados.png` (matplotlib).
- `../documento_borrador.md`: el mismo contenido en texto, para revisar.

Al abrir el .docx en Word, el índice se completa al actualizar campos (Word lo pregunta;
si no, clic derecho sobre el índice → Actualizar campo).
